ROBOMISIÓN LAB — SOLUCIONARIO DOCENTE — LISTO PARA GITHUB PAGES
=============================================================

ESTE ZIP ES PARA EL REPOSITORIO PUBLICO "solucionario" (NO PARA "robomision-lab").

ARCHIVOS QUE DEBES SUBIR A LA RAÍZ DEL REPOSITORIO:
  index.html                  Página principal, imprescindible para abrir la raíz
  docentes.html               Misma web, compatible con la dirección anterior
  docentes-datos.enc.json     Solucionarios cifrados (obligatorio, ~10 MB)
  .nojekyll                   Evita procesamientos Jekyll de GitHub Pages
  404.html                    Página de error amigable
  LEEME_PRIMERO.txt           Estas instrucciones

PASOS:
  1. Descarga y DESCOMPRIME el ZIP (no subas el ZIP sin descomprimir).
  2. En github.com/manuelpdb/solucionario, pestaña Code, rama main,
     pulsa Add file > Upload files. Arrastra todos los archivos de la
     carpeta SOLUCIONARIO_ROBOMISION_LISTO_GITHUB (NO la carpeta como nivel adicional).
  3. Confirma con "Commit changes".
  4. En Settings > Pages verifica: Deploy from a branch / main / /(root).
     Espera a que la publicación termine, revisa Actions o el mensaje de Pages.
  5. Abre https://manuelpdb.github.io/solucionario/
     Alternativa: https://manuelpdb.github.io/solucionario/docentes.html
  6. Contraseña: CEPDEJEREZ

IMPORTANTE:
  - Debes ver index.html y docentes-datos.enc.json al mismo nivel que README,
    directamente en la primera pantalla del repositorio.
  - Si la URL SIGUE MOSTRANDO un error 404, GitHub Pages no está sirviendo
    esa dirección o no ha terminado el despliegue. El ZIP por sí solo NO
    puede activar GitHub Pages. Comprueba Settings > Pages y Actions.
  - Si se ve el formulario, pero la contraseña no carga los contenidos,
    comprueba que docentes-datos.enc.json esté publicado en la misma carpeta.
  - Se precisa un navegador reciente con HTTPS para el descifrado.
  - El código y las soluciones son orientativos y NO están todos verificados.
  - No subas los ZIP antiguos con las soluciones sin cifrar.
